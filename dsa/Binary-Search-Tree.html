Binary Search Tree (BST)

A Binary Search Tree (BST) is a type of binary tree that organizes values according to a specific ordering rule, making it easier to locate, insert, and remove data while maintaining that order.

The defining rule is simple: for any node, values smaller than it are placed in its left subtree, while values greater than it are placed in its right subtree. This rule applies throughout the structure, not just to the immediate children.

Imagine a library where books are arranged according to their identification numbers. If you are looking for book 50, you check a book labeled 50. If the current book is numbered 70, you know your target belongs on the lower-numbered side. If it is numbered 30, you know to look on the higher-numbered side. Each comparison helps you choose the appropriate direction.

For example, imagine inserting the values 50, 30, 70, 20, and 40 into a BST. The value 50 becomes the starting value, 30 belongs to its left, and 70 belongs to its right. The values 20 and 40 are then positioned according to the same ordering rule.

One important distinction: a BST does not automatically keep itself balanced. If values are inserted in an unfortunate order, its shape can become highly uneven. The ordering rule still holds, but the structure may lose much of its practical advantage.


Where Are BSTs Useful?

Ordered Data Management: Useful when information needs to remain organized by keys, such as employee IDs or product codes.

Lookup Systems: Can help locate a particular value without having to examine every stored value in a well-shaped tree.

Range-Based Queries: Useful when you need values within a particular interval, such as product prices between two amounts.

Dynamic Collections: Suitable when values are frequently added or removed while their ordering must be preserved.


Summary

A Binary Search Tree is like a carefully organized filing system where smaller values go to the left and larger values go to the right. Its defining strength is that every value has a predictable position based on its relationship to other values.
