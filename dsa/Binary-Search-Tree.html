Binary Search Tree

A Binary Search Tree (BST) is a special type of binary tree that enforces a strict ordering rule across all its nodes: for any given node, every value in its entire left subtree is smaller, and every value in its entire right subtree is larger.

Imagine playing a "higher or lower" number-guessing game between 1 and 100. You start at the root by guessing 50. If the target number is smaller than 50, you step left and immediately eliminate 50 through 100 from consideration; if it is larger, you step right and eliminate 1 through 50. A binary search tree turns this guessing game into a physical structure.


Understanding the Basic Terminology

BST Ordering Property: The core invariant that `left_descendants < parent < right_descendants` holds true for every single node in the tree.

In-Order Traversal: Visiting the left subtree first, then the current node, and finally the right subtree-which automatically reads out all stored values in sorted ascending order.

In-Order Successor / Predecessor: The node with the next largest (or next smallest) value in the tree, used to replace a node when it is deleted.

Skewed (Degenerate) Tree: An unbalanced binary search tree where items were inserted in already-sorted order, causing the tree to stretch into a slow, single-file chain.


How Does a Binary Search Tree Work Conceptually?

Whenever you search for or insert a value, you compare your value against the current node starting at the root. If your value is smaller, you move to the left child; if larger, you move to the right child. At every step down the tree, you cut the remaining search space roughly in half.

As long as the tree remains reasonably balanced, searching, inserting, and deleting take time proportional to the tree's height ($\mathcal{O}(\log n)$) rather than scanning through every item. Plus, unlike a hash table, a binary search tree keeps all its data in sorted order at all times.


Where Are Binary Search Trees Used in the Real World?

Sorted Map and Set Libraries: Power ordered data collections where users need to iterate through keys alphabetically or numerically.

Range Queries in Databases: Quickly find all records whose prices fall between ¥20 and ¥50 without scanning the entire database.

Auto-Complete and Leaderboards: Maintain live rankings where scores are constantly updated and queried by rank or range.


Summary

A binary search tree combines the dynamic flexibility of a linked structure with the speed of binary search, keeping elements continuously sorted as items are added and removed.
