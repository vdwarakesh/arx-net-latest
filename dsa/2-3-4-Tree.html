2-3-4 Tree

A 2-3-4 Tree is a self-balancing search tree in which each internal node can contain one, two, or three keys and have two, three, or four children, respectively.

The keys within each node are sorted and divide the values into distinct ranges. Like a 2-3 Tree, it maintains perfect balance by keeping all leaves at the same depth. Its nodes can accommodate more keys and branches, allowing the structure to organize information with fewer levels in many situations.

Imagine a road junction that can direct traffic through two, three, or four exits depending on how many routes it needs to manage. Each junction contains signs that help travelers choose the correct direction, while the overall road system remains balanced.

A notable connection is that a 2-3-4 Tree is structurally related to a Red-Black Tree. Red-Black Tree representations can encode the multi-key nodes of a 2-3-4 Tree using nodes connected by red links, which is one reason the two structures are often studied together.


Where Is It Useful?

A 2-3-4 Tree is useful for understanding balanced search structures, multiway indexing, and how more complex balanced trees can be represented using simpler node relationships.


Summary

A 2-3-4 Tree allows each internal node to hold up to three keys and have up to four children, maintaining balance while organizing ordered data across multiple branches.
