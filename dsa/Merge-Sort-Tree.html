Merge Sort Tree

A Merge Sort Tree is a special type of segment tree in which every node stores a **complete sorted list** of all elements inside its interval, capturing every intermediate merging stage of the Merge Sort algorithm in a permanent, queryable tree structure.

Imagine a school principal who wants to know how many students in classrooms 4 through 9 scored above 85% on an exam. In a Merge Sort Tree, every wing and hallway of the school keeps a pre-sorted roster of its students' scores. The principal simply checks three hallway rosters covering classrooms 4–9 and uses binary search on each sorted list to count the high scorers in an instant.


Understanding the Basic Terminology

Sorted Subarray Vector: Instead of storing a single sum or minimum integer, a node covering $[L, R]$ stores a sorted array of all $R - L + 1$ elements in that range.

In-Node Binary Search (`lower_bound` / `upper_bound`): Searching the sorted list inside a canonical segment tree node to count how many elements are less than, greater than, or between given bounds.

$\mathcal{O}(n \log n)$ Space Footprint: Because the tree has $\log_2 n$ levels and each level contains all $n$ elements distributed across its nodes, the entire structure uses $n \log_2 n$ memory.


How Does a Merge Sort Tree Work Conceptually?

When building a Merge Sort Tree from the bottom up, each leaf holds a single 1-element array. Each parent node merges the two already-sorted lists of its left and right children in linear time-just like the standard Merge Sort algorithm-except it saves those merged lists inside the nodes forever.

When you ask *"How many numbers in subarray $[L, R]$ are strictly less than $K$?"*, the segment tree splits $[L, R]$ into $\mathcal{O}(\log n)$ canonical nodes and runs a fast binary search ($\mathcal{O}(\log n)$) inside each node's sorted list, answering the query in $\mathcal{O}(\log^2 n)$ time.


Where Are Merge Sort Trees Used in the Real World?

2D Orthogonal Range Counting: Count how many data points fall inside a rectangular window $[x_1, x_2] \times [y_1, y_2]$ on a map or scatter plot.

Analytical Database Filtering: Count how many transactions within a specific index/time slice exceeded a dollar threshold.

Subarray Rank and Order Queries: Find the smallest element greater than $X$ within any arbitrary subarray.


Summary

A Merge Sort Tree saves the sorted sub-lists of Merge Sort inside a segment tree, allowing you to binary search across any slice of an array to count and filter values by threshold.
