Sparse Table

A Sparse Table is a 2D array-based data structure designed for immutable (static) arrays that precalculates answers over power-of-two interval lengths (20, 21, 22, 23, ...) so it can answer Range Minimum Queries (RMQ) and Range Maximum Queries in constant O(1) time.

Imagine wanting to know the lowest daily temperature over a 12-day vacation from Day 3 to Day 14. Instead of checking all 12 days one by one, you have a reference chart that already lists the lowest temperature for every 8-day block starting on any day. You simply check two overlapping 8-day blocks: Days 3-10 (8 days) and Days 7-14 (8 days). Even though Days 7-10 overlap in the middle, taking the minimum of those two precalculated numbers gives you the exact lowest temperature across all 12 days in a single step!


Understanding the Basic Terminology

Idempotent Operation: A mathematical operation where overlapping the same element twice does not change the answer-such as min(x, x) = x, max(x, x) = x, gcd(x, x) = x, or bitwise AND / OR (unlike addition +, where overlapping double-counts the middle).

Power-of-Two Table (st[k][i]): A 2D table of size (⌊log2 n ⌋ + 1) × n where st[k][i] stores the answer for the interval of length 2k starting at index i (covering [i, i + 2k - 1]).

Overlapping Two-Block Query: Covering any interval [L, R] of length len = R - L + 1 using two blocks of size 2k (where k = ⌊log2(len) ⌋): min(st[k][L], st[k][R - 2k + 1]).


How Does a Sparse Table Work Conceptually?

Building the Sparse Table uses dynamic programming row by row: Row 0 (st[0][i]) is just the original array (blocks of length 20 = 1). Every higher row k is computed by combining two adjacent halves of length 2k-1 from the row below: st[k][i] = min(st[k-1][i], st[k-1][i + 2^(k-1)]), taking O(n log n) time and space total.

Once built, any range minimum or maximum query [L, R] of any length is answered in strictly O(1) time by comparing just two cells in the table-beating even a Segment Tree's O(log n) query speed when the underlying array doesn't change.


Where Are Sparse Tables Used in the Real World?

Lowest Common Ancestor (LCA) in Trees: Convert tree LCA queries into O(1) Range Minimum Queries over the tree's flattened Euler Tour depth array.

Suffix Array Longest Common Prefix (LCP) Queries: Find the longest common prefix between any two substrings of a text in O(1) time by querying the RMQ of the static LCP array.

Static Historical Analytics: Answer millions of instant min/max range queries over archived sensor logs or historical financial datasets.


Summary

A Sparse Table precomputes power-of-two blocks across a static array, using the clever overlap of two blocks to answer range minimum, maximum, and GCD queries in constant O(1) time.
