Segment Tree

A Segment Tree is a tree-based data structure designed to answer queries about specific ranges of an array while allowing the underlying values to change.

Instead of storing only individual elements, it organizes information about segments, or continuous portions, of the array. Each node represents a range and stores a summary of that range, such as its sum, minimum, maximum, or greatest common divisor. The type of summary depends on the problem being solved.

Imagine a school tracking students' marks across several classes. You might want to find the total marks of students numbered 10 through 20, then update one student's mark and ask the same question again. A Segment Tree organizes summaries of different groups so that range-based questions can be answered without repeatedly processing the entire collection.

Its main strength is that it supports both range queries and updates, making it useful when data changes frequently.


Where Is It Useful?

Segment Trees are used in competitive programming, financial data analysis, scheduling systems, and applications that repeatedly calculate summaries over intervals.


Summary

A Segment Tree divides an array into manageable ranges and stores summaries of those ranges, making it useful for answering questions about portions of frequently changing data.
