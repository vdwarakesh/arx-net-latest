Segment Tree

A Segment Tree is a special type of binary tree that stores precalculated summary information about contiguous intervals (segments) of an array, enabling both **range queries** (like finding the sum, minimum, or maximum over any sub-array) and **element updates** in fast $\mathcal{O}(\log n)$ time.

Imagine a company CEO who wants to know total sales from Day 3 to Day 14. Instead of adding up twelve daily receipts one by one, the accounting hierarchy already has weekly totals, 4-day totals, and 2-day totals pre-calculated in a tree. The CEO simply asks three managers whose time blocks neatly cover Days 3–14 and adds their three numbers together in an instant.


Understanding the Basic Terminology

Segment (Interval $[L, R]$): The contiguous slice of array indices represented by a specific node in the tree.

Leaf Node: A bottom node representing a single individual array element at index $[i, i]$.

Internal Node Merge Operation: The associative function (such as addition `+`, `min`, `max`, or `gcd`) used to combine the left child's $[L, mid]$ summary and right child's $[mid+1, R]$ summary.

Lazy Propagation: A powerful technique where range updates (like adding `+5` to indices 100 through 5,000) are stored as pending notes on high-level nodes and only pushed down to children when needed.


How Does a Segment Tree Work Conceptually?

The root of a segment tree represents the entire array $[0, n-1]$. Its left child covers the first half $[0, mid]$, and its right child covers the second half $[mid+1, n-1]$, continuing down until the leaves hold single array elements.

When a single array element changes, only the $\log_2 n$ ancestor intervals containing that index need to be recalculated. When you query an arbitrary range $[qL, qR]$, the tree decomposes your range into at most $2 \log_2 n$ precomputed canonical blocks-giving you instant answers even when the underlying data changes thousands of times a second.


Where Are Segment Trees Used in the Real World?

Financial Time-Series Analytics: Query the highest, lowest, or average stock price across any custom date/time window while live trades stream in.

Computational Geometry & GIS: Count overlapping rectangles, calculate union areas of map regions, and resolve spatial range queries.

Database Range Aggregations: Accelerate `SUM`, `MIN`, and `MAX` queries over dynamic numerical columns.


Summary

A segment tree divides an array into a balanced hierarchy of precalculated intervals, turning slow range scans and bulk updates into lightning-fast logarithmic operations.
