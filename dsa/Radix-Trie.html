Radix Trie

A Radix Trie is a type of Compressed Trie that stores strings by grouping sequences of characters into edge labels instead of creating a separate node for every character.

When several characters occur consecutively without a branching point, they can be represented together on a single edge. When strings share a prefix, their paths remain shared until they reach a point where the strings differ or a stored word ends.

For example, imagine storing the words “star,” “start,” and “stay.” The shared beginning “sta” can be represented as a common path, with branches appearing where the words diverge. This avoids unnecessary nodes while preserving the ability to distinguish the stored words.

Think of a subway map. Instead of marking every meter of track, the map shows long stretches between stations and highlights the places where routes split. The result is a simpler representation without losing important connections.


Where Is It Useful?

Radix Tries are used in dictionaries, IP routing tables, autocomplete systems, and search indexes where efficient prefix matching and reduced memory overhead are important.


Summary

A Radix Trie compresses character paths into longer edge labels, keeping shared prefixes and branching points while avoiding unnecessary nodes.
