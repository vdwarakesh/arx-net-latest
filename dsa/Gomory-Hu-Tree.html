Gomory-Hu Tree

A Gomory-Hu Tree is a specialized weighted tree that represents the minimum-cut relationships between every pair of vertices in an undirected, capacitated graph.

A minimum cut is the smallest total capacity of edges whose removal separates one vertex from another. Finding this value independently for every possible pair can be expensive. A Gomory-Hu Tree compresses these pairwise minimum-cut values into a single weighted tree.

The important property is that the minimum-cut value between any two original vertices can be obtained from the minimum edge weight along the tree path connecting their corresponding vertices.

Imagine a country with many cities connected by roads, where every road has a capacity representing how much traffic it can carry. You want to know the weakest connection separating any two cities. A Gomory-Hu Tree summarizes these separation strengths in one structure rather than requiring a separate representation for every city pair.


Where Is It Useful?

Gomory-Hu Trees are useful in network reliability analysis, communication networks, transportation planning, and graph problems involving repeated minimum-cut queries.


Summary

A Gomory-Hu Tree compresses pairwise minimum-cut information for an undirected network into a weighted tree, making it easier to compare the strength of connections between different pairs of vertices.
