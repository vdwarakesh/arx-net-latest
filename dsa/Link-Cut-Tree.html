Link-Cut Tree

A Link-Cut Tree is a specialized data structure designed to maintain a forest of trees while supporting changes to their connections and queries about relationships between nodes.

Its main purpose is to manage a changing network of tree-shaped connections. It can support operations such as linking two separate trees, cutting an existing connection, and examining relationships along a path between two nodes.

Imagine a railway network where stations are connected by routes that change over time. A new route may connect two separate networks, or an existing route may be removed. You may also need to ask questions about the stations along a particular route. A Link-Cut Tree helps manage this changing structure without rebuilding the entire network after every change.

Despite its name, a Link-Cut Tree is not simply a fixed tree. It is a sophisticated data structure that rearranges its internal representation as needed to manage a changing forest.


Where Is It Useful?

Link-Cut Trees are useful in dynamic graph problems involving tree connections, network maintenance, connectivity-related queries, and advanced competitive programming problems.


Summary

A Link-Cut Tree manages changing tree connections and supports queries about paths between nodes, making it useful when the relationships in a tree-shaped network frequently change.
