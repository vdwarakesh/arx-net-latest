Suffix Array

A Suffix Array is a special type of string data structure that consists of a flat array of integers representing the starting indices of all suffixes of a string, arranged in sorted lexicographical (alphabetical) order.

Imagine wanting all the search power of a massive Suffix Tree without paying for all its complex pointers and tree nodes. Instead, you list the starting page and character position of every suffix in a text, and sort those position numbers alphabetically by the text that starts there. Because every matching phrase now clusters together in one contiguous block of the sorted array, simple binary search can find any substring in an instant!


Understanding the Basic Terminology

Suffix Index (SA[i]): An integer stored at position i of the suffix array indicating that the i-th alphabetically smallest suffix begins at character index SA[i] in the original text.

LCP Array (Longest Common Prefix Array): A companion array of size n where LCP[i] stores how many starting characters the sorted suffix SA[i] shares with its immediate neighbor SA[i-1].

SA-IS / Prefix-Doubling Algorithms: Fast construction methods that sort all n suffixes in O(n) or O(n log n) time without comparing full strings from scratch.


How Does a Suffix Array Work Conceptually?

Take the string "BANANA". Its suffixes start at indices 0 ("BANANA"), 1 ("ANANA"), 2 ("NANA"), 3 ("ANA"), 4 ("NA"), and 5 ("A"). Sorting those suffixes alphabetically gives "A", "ANA", "ANANA", "BANANA", "NA", "NANA"-so the Suffix Array is simply the integer list [5, 3, 1, 0, 4, 2].

Because every substring is a prefix of some suffix, all occurrences of any pattern (like "AN") sit right next to each other in the Suffix Array (3 and 1). Two quick binary searches locate the exact range of matches, using 5x to 10x less memory than a pointer-heavy Suffix Tree.


Where Are Suffix Arrays Used in the Real World?

Bioinformatics Read Alignment (Bowtie, BWA, STAR): Map millions of short DNA sequencing reads against the 3-billion-letter human genome on a standard desktop computer.

Data Compression (Burrows-Wheeler Transform / bzip2): Generate the BWT permutation directly from the sorted suffix order to cluster identical characters for compression.

Full-Text Search Engines: Index large source-code repositories and offline encyclopedias for instant substring queries.


Summary

A suffix array replaces the bulky pointers of a suffix tree with a clean, sorted array of starting indices, delivering full-text substring search in a tiny fraction of the memory.
