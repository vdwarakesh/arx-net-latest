Compressed Trie

A Compressed Trie is a type of Trie that reduces unnecessary nodes by combining chains of nodes with only one child into a single edge labeled with a sequence of characters.

In a regular Trie, a long word can create many individual nodes, one for each character. A Compressed Trie simplifies these paths by storing groups of characters together. Branching points and word endings remain distinguishable, so the structure can still represent the stored strings correctly.

Imagine a road map where several stretches of road have no intersections. Instead of marking every tiny stretch separately, the map combines them into one longer road between important junctions. The map becomes less cluttered while preserving the routes that matter.


Where Is It Useful?

Compressed Tries are useful in dictionaries, search indexes, network routing tables, and applications that need prefix-based lookups while reducing the memory overhead of storing many strings.


Summary

A Compressed Trie saves space by merging long, non-branching character paths into longer labeled edges, keeping the useful structure without all the extra stops.
