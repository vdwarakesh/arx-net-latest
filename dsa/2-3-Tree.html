2-3 Tree

A 2-3 Tree is a self-balancing search tree in which each internal node can be either a 2-node or a 3-node. A 2-node contains one key and has two children, while a 3-node contains two keys and has three children.

The keys inside each node remain sorted and divide the possible values into ordered ranges. The tree maintains perfect balance, meaning all leaves appear at the same depth. When values are inserted or removed, the structure adjusts to preserve these properties.

Imagine a road junction with either two exits or three exits. Signs at the junction tell you which direction to take based on the value you are looking for. Because the junctions are organized in balanced levels, no destination is disproportionately far from the starting point.

The 2-3 Tree is an important example of a balanced search structure that allows multiple keys per node rather than limiting every node to a single key.


Where Is It Useful?

It is useful for understanding balanced search-tree design and the principles behind maintaining ordered data in a consistently balanced structure.


Summary

A 2-3 Tree maintains sorted data using nodes with either one key and two children or two keys and three children, while keeping all leaves at the same depth.
