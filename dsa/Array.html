Array

An Array is a linear data structure that stores elements in an ordered sequence, with each element identified by its position, called an index. Arrays make it easy to organize related information, such as scores, temperatures, or product prices, in one place.

Think of an array as a row of numbered lockers. Each locker holds one item, and its number helps you find that item directly. The elements are arranged in a defined order, so their positions matter.

Arrays are useful when a program needs to store and access collections of related data, such as student marks, daily sales figures, or the seats in a theater.


Summary

An Array organizes elements into an indexed sequence, making information easy to locate and manage by position.
