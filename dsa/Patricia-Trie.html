Patricia Trie

A Patricia Trie (short for **Practical Algorithm to Retrieve Information Coded in Alphanumeric**) is a special type of compressed trie that operates as a **binary radix tree** (radix = 2), where every internal node stores the exact bit index to test next, completely eliminating one-way branches and redundant substring storage.

Imagine identifying a mystery vehicle using only a minimalist checklist of numbered Yes/No questions: Step 1 jumps straight to Question #4 (*"Does it have two wheels?"*), and if Yes, jumps straight to Question #19 (*"Does it have a motor?"*). You completely skip all questions in between where every candidate has the exact same answer, and you only carefully verify the full license plate once you reach the final parking spot.


Understanding the Basic Terminology

Critical Bit Index (Skip Count): The exact bit position stored inside an internal node where at least two keys in its subtree first differ (`0` goes left, `1` goes right).

Binary Branching (Radix 2): Every internal node has strictly two children-one for bit `0` and one for bit `1` at that critical bit position.

Upward Back-Pointers (or Leaf Keys): Storing full keys only at the leaves (or via upward pointers) and performing a single final equality check at the end of a search to verify all skipped bits match.


How Does a Patricia Trie Work Conceptually?

Instead of storing intermediate substring slices on every edge, a Patricia trie views every key as a stream of bits (`0`s and `1`s). Each internal node stores only an integer bit offset-for example, *"Check bit #23."* During a search, you don't even examine bits 1 through 22; you jump straight to bit #23 of your query key, branch left for `0` or right for `1`, and continue until you land on a leaf.

Once you reach the leaf, you compare your query key against the full key stored at that leaf one time. If they match, the key is found; if not, the first bit where they disagree tells you the exact spot to insert a new node.


Where Are Patricia Tries Used in the Real World?

Internet Backbone IP Routing (BGP / CIDR): Perform Longest Prefix Matching on 32-bit IPv4 and 128-bit IPv6 network addresses at line speed.

Blockchain State Trees (Ethereum Modified Merkle Patricia Trie): Store cryptographic state and account balances where keys are 256-bit hashes.

Network Packet Filters: Match subnet masks and routing rules in BSD and Linux networking stacks.


Summary

A Patricia trie is an ultra-compact, bit-level compressed trie that skips straight to the exact bits where keys differ, making it the gold standard for IP routing and blockchain state storage.
