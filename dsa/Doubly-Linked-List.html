Doubly Linked List

A Doubly Linked List is a type of linked list in which each node stores data and two links: one to the next node and another to the previous node. This allows movement in both directions through the sequence.

Imagine a music playlist where you can press Next to move forward or Previous to return to the song you just heard. Each song's position is connected to both its successor and its predecessor, making navigation in either direction possible.

Doubly linked lists are useful in browser navigation, undo and redo features, and systems that need to move backward and forward through items. Maintaining two links per node requires additional memory, but it makes certain navigation and removal operations more convenient.


Summary

A Doubly Linked List connects each node to both its neighbors, supporting movement in either direction.
