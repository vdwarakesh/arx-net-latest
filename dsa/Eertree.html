Eertree

An Eertree (also known as a Palindromic Tree; its name is a playful palindrome-style reversal of "tree") is a special type of tree-like graph structure that stores every distinct palindromic substring of a string in linear O(n) space and time.

Imagine building snowmen from the inside out: you start with either a single snowball in the center (for odd-length palindromes like "ABA") or two touching snowballs (for even-length palindromes like "ABBA"). Every time you step down a branch in an eertree, you wrap the exact same matching letter onto *both* the front and the back of the current palindrome (P → x + P + x).


Understanding the Basic Terminology

Dual Roots (Length -1 and Length 0): An eertree actually has two roots: an imaginary root of length -1 (so wrapping 'a' around it yields the 1-letter palindrome "a", since -1 + 2 = 1) and an empty-string root of length 0 (so wrapping 'a' around it yields "aa").

Palindrome Extension Edge (x): A directed edge labeled with character x from node P to node xPx, adding x to both ends simultaneously.

Suffix Link (Longest Palindromic Proper Suffix): A fallback pointer from each palindrome node to the longest smaller palindrome that sits at its right end, similar to failure links in Aho-Corasick or Suffix Trees.


How Does an Eertree Work Conceptually?

A fundamental theorem of string theory states that adding one character to the end of a string can create **at most one new distinct palindrome**, which means a string of length n contains at most n distinct palindromic substrings total!

As you process a string character by character from left to right, the eertree follows suffix links from the longest palindrome ending at the previous position until it finds one preceded by the new character c. It then either steps along an existing c edge or creates one new node-constructing the entire catalog of all palindromes in O(n) time.


Where Are Eertrees Used in the Real World?

RNA Secondary Structure & Genomic Hairpin Analysis: Detect palindromic and inverted-repeat sequences in DNA and RNA strands where molecules fold back on themselves.

Palindrome Partitioning & Counting: Count total palindromic substrings, find longest common palindromes, or factor strings into minimal palindromic pieces.

Text Compression & Formal Language Theory: Analyze symmetric structural symmetries in strings and biological sequences.


Summary

An eertree is a compact dual-rooted structure where edges wrap matching characters around both ends of a center, indexing every distinct palindrome of a string in linear time and space.
