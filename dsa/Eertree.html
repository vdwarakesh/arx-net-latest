Eertree

An Eertree, also called a palindromic tree, is a specialized data structure designed to represent the distinct palindromic substrings of a string.

A palindrome is a sequence that reads the same forward and backward, such as “level,” “madam,” or “abba.” An Eertree maintains a compact structure representing the distinct palindromes found in the text, along with information that connects longer palindromes to smaller ones.

For example, in the string “ababa,” palindromic substrings include “a,” “b,” “aba,” “bab,” and “ababa.” An Eertree organizes these distinct patterns and can be updated as new characters are added to the string.

Imagine a language researcher studying a long passage and wanting to discover every distinct word pattern that reads identically in both directions. An Eertree acts like a specialized index that keeps track of these patterns as the passage grows.


Where Is It Useful?

Eertrees are useful in string analysis, competitive programming, palindrome-related text processing, and applications that need to track palindromic patterns in sequences.


Summary

An Eertree is a specialized structure for organizing distinct palindromic substrings, making it useful when symmetrical character patterns are the focus.
