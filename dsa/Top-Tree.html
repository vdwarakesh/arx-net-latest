Top Tree

A Top Tree is a special type of hierarchical dynamic tree data structure that generalizes both Link-Cut Trees and Euler Tour Trees by recursively contracting pairs of connected subtrees (**clusters**) using two operations—`Compress` and `Rake`—allowing it to handle both **path queries** and **subtree queries** simultaneously in $\mathcal{O}(\log n)$ time.

Imagine folding up a sprawling road map of a country. First, whenever you see a side dead-end road branching off a highway, you fold that dead-end neatly onto the highway junction (`Rake`). Second, whenever two highway segments meet end-to-end with no other branches between them, you fold them into a single shorter segment (`Compress`). Repeating those two folds shrinks any tree down to one single master cluster in logarithmic steps.


Understanding the Basic Terminology

Cluster: A connected subgraph of the underlying tree that interacts with the rest of the tree through at most two **boundary vertices**.

Path Cluster (2 Boundary Vertices): A cluster with two boundary endpoints $(a, b)$, representing a main path connecting $a$ and $b$ plus any side branches hanging off its interior.

Point Cluster (1 Boundary Vertex): A cluster with only one boundary vertex $(a)$, representing a hanging dead-end subtree attached to the rest of the tree only at $a$.

`Compress` and `Rake` Operations: `Compress` joins two path clusters end-to-end along their shared boundary vertex; `Rake` folds a point cluster (a side branch) onto an adjacent cluster.


How Does a Top Tree Work Conceptually?

Link-Cut Trees can easily query paths but struggle with subtrees; Euler Tour Trees easily query subtrees but struggle with paths. A Top Tree unifies both worlds by representing every single edge of the original tree as a base cluster, and building a balanced binary hierarchy of `Compress` and `Rake` merges on top of them.

Because every node in the Top Tree summarizes a cluster with at most 2 boundary vertices, you can dynamically link, cut, update paths, update subtrees, and even run tree-search routines (like finding a tree's diameter or center/median) in $\mathcal{O}(\log n)$ time per operation.


Where Are Top Trees Used in the Real World?

Dynamic Tree Center & Median Maintenance: Track the optimal facility location (minimizing maximum or total distance to all nodes) as network links and node weights change.

Combined Path + Subtree Dynamic Queries: Solve problems requiring simultaneous updates to root-to-node paths and queries over full subtrees.

Higher-Connectivity Dynamic Graph Algorithms: Maintain 2-edge-connected and biconnected components in dynamic networks.


Summary

A Top Tree is the ultimate generalization of dynamic trees, folding side branches (`Rake`) and paths (`Compress`) into a unified hierarchy that handles both path and subtree operations in logarithmic time.
