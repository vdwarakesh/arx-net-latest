Hash Map

A Hash Map (also called a Dictionary or Associative Array) is a special type of hash table that stores data as Key-Value pairs, where every unique key maps directly to an associated value.

Imagine a contact list on your smartphone. Each person's name is the Key, and their phone number is the Value. You never search your contacts by "Slot #14"; you search by the name "Alice", and the phone immediately retrieves Alice's phone number. No two contacts share the exact same unique identifier key, though two people might share the same home phone number.


Understanding the Basic Terminology

Key: The unique identifier used to index, store, and look up an entry (for example, a username or product SKU). Keys must be hashable.

Value: The payload or information stored alongside a key (for example, a user profile object or item price).

Key-Value Pair (Entry): The combined unit of a key and its corresponding value stored together inside a hash bucket.


How Does a Hash Map Work Conceptually?

When you store a pair like ("apple", 1.99) in a hash map, only the key ("apple") is fed into the hash function to determine which bucket the pair lands in. The value (1.99) simply rides along with the key. If you insert a new value using a key that already exists in the map, the hash map locates the existing key and overwrites its old value with the new one, guaranteeing that keys remain strictly unique.


Where Are Hash Maps Used in the Real World?

JSON and Configuration Objects: Represent structured settings and API payloads (such as mapping "theme" to "dark").

Counting Frequencies: Count how many times each word appears in a book by mapping each word (key) to its running tally (value).

User Session Stores: Map a browser's unique session cookie ID to the logged-in user's account data.


Summary

A hash map connects unique keys to their values with instant lookup speed, serving as the go-to structure whenever you need to label and retrieve data by name rather than by position.
