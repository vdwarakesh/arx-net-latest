Min-Heap

A Min-Heap is a type of Binary Heap in which every parent node contains a value less than or equal to the values of its children. Consequently, the smallest value in the collection is always at the root.

The important point is that the entire collection is not necessarily sorted. The structure only guarantees that each parent is no greater than its children, so smaller values can be found deeper in different branches.

Imagine a collection of pending bills where the smallest amount must be identified first. A min-heap keeps the smallest amount at the top, making it immediately accessible whenever needed.


Where Is It Useful?

Min-heaps are useful for processing the earliest scheduled event, selecting the smallest available value, managing jobs by ascending cost, and handling tasks where the lowest numerical priority value should be selected first.


Summary

A Min-Heap keeps the smallest value at the top, making it ideal when the next item to process is the one with the lowest value.
