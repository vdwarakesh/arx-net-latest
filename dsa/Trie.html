Trie

A Trie (pronounced "try" or "tree", derived from re**trie**val, and also called a **Prefix Tree**) is a special type of tree that stores strings character by character along its branches so that words sharing a common prefix share the exact same path from the root.

Imagine looking up words in a road atlas where the first intersection asks for the 1st letter (`C`), the next fork asks for the 2nd letter (`A`), and the third fork splits into `T` ("CAT"), `R` ("CAR"), and `P` ("CAP"). All three words travel down the exact same `C -> A` highway before branching off at the very last letter.


Understanding the Basic Terminology

Root Node: The topmost node representing an empty string (`""`), from which all first-letter branches originate.

Character Edge / Child Map: A link from a parent node to a child node labeled with a single character of the alphabet.

Prefix Path: The sequence of characters formed by walking from the root down to any internal node.

End-of-Word Marker (`isEnd`): A boolean flag (or terminal marker) on a node indicating that the path from the root to this node spells out a complete, valid word—not just a prefix of a longer word.


How Does a Trie Work Conceptually?

Unlike a Binary Search Tree or Hash Table, which compares or hashes entire strings at once, a trie breaks each string into individual characters. To look up a 5-letter word like `"APPLE"`, you start at the root and take five steps: `A -> P -> P -> L -> E`.

The lookup speed depends **only on the length of the word** ($L$), completely independent of whether the trie stores 100 words or 100 million words! Furthermore, once you walk to the node for `"APP"`, every single word starting with `"APP"` sits directly inside the subtree beneath you.


Where Are Tries Used in the Real World?

Search Engine Auto-Complete: Instantly suggest `"weather today"`, `"weather tomorrow"`, and `"weather radar"` the moment a user types `"weath"`.

Smartphone Keyboard Predictive Text and Spell Check: Validate words and suggest completions as fingers tap each letter.

Contact Book Prefix Search: Filter contacts in real time as you type the first few letters of a name or digits of a phone number.


Summary

A trie is a character-by-character prefix tree that merges shared word beginnings, making prefix searches and auto-complete suggestions blazingly fast regardless of dictionary size.
