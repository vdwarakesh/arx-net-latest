B+ Tree

A B+ Tree is a special type of B-tree in which all actual data records (or data pointers) are stored exclusively in the leaf nodes, while internal nodes store only routing copies of keys, and all leaf nodes are linked together side by side in a sequential chain.

Imagine an encyclopedia set where the thin index booklet at the front contains only topic names and page numbers-no long articles cluttering the index. Once the index points you to Volume 4, Page 120, every page at the bottom is numbered consecutively so you can simply turn the pages forward to read everything from "Mozart" through "Nivaldi" without ever flipping back to the index booklet.


Understanding the Basic Terminology

Routing Keys (Internal Nodes): Lightweight separator keys stored in non-leaf nodes solely to guide searches down toward the correct leaf.

Data Leaves: The bottom-most level of the tree where every single key and its associated data record reside.

Sibling Leaf Pointers: Forward (and often backward) linked-list pointers connecting each leaf node directly to its next sorted neighbor.


How Does a B+ Tree Work Conceptually?

In a classic B-tree, both internal nodes and leaf nodes hold bulky data payloads, which reduces how many keys can fit inside an internal routing node and makes scanning a range of values require awkward up-and-down tree traversal.

A B+ tree strips all bulky data out of the internal nodes so they can pack in even more routing keys, making the tree even shallower. And because the bottom leaf nodes contain every key in sorted order and link directly to one another like a linked list, scanning a range of 10,000 records is as fast as walking down to the starting leaf once and gliding straight across the bottom chain.


Where Are B+ Trees Used in the Real World?

Relational Database Management Systems (RDBMS): Serve as the default indexing engine for MySQL (InnoDB), PostgreSQL, SQLite, Oracle, and Microsoft SQL Server.

SQL Range Queries (BETWEEN, >, <):< /strong> Execute queries like SELECT * FROM orders WHERE date BETWEEN '2026-01-01' AND '2026-03-01' via a single leaf search followed by a sequential leaf scan.

Modern File System Directories: Index large directories and file extents in XFS, NTFS, and ReiserFS.


Summary

A B+ tree refines the B-tree by keeping internal nodes pure for routing and linking all data-holding leaves into a bottom chain, delivering both rapid single lookups and unmatched range-scan speeds.
