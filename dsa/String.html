String

A String is a linear data structure that stores an ordered sequence of characters—such as letters, digits, punctuation marks, and emojis—used to represent human-readable text or raw symbol sequences in a computer.

Imagine a beaded necklace where each bead has a single letter etched onto it. The order of the beads matters completely—swapping the letters in `"LISTEN"` turns it into `"SILENT"`—and the necklace as a whole forms a single meaningful word or sentence. A string organizes characters in this exact sequential chain.


Understanding the Basic Terminology

Character & Character Encoding: A single symbol mapped to a numerical code in memory using standards like ASCII (1 byte per character) or UTF-8 / Unicode (1 to 4 bytes per character).

Substring: Any contiguous slice of characters taken from inside a string (for example, `"GRAM"` inside `"PROGRAM"`).

Prefix and Suffix: A substring that starts at the very first character (prefix) or ends at the very last character (suffix) of the string.

Concatenation: Joining two strings end-to-end to form a longer string.

Lexicographical Order: Alphabetical dictionary ordering determined by comparing two strings character by character from left to right.


How Does a String Work Conceptually?

Under the hood, a string is built on top of an **Array** of numeric character codes, often accompanied by an explicit `length` field (or terminated by a special zero byte `\0` in languages like C). Because it is backed by a contiguous array, reading the $i$-th character of a fixed-width string is instantaneous, while operations like pattern matching, slicing, and concatenation scan across the character array sequentially.


Where Are Strings Used in the Real World?

User Interfaces and Web Pages: Display every piece of text, HTML markup, URL, and message on digital screens.

Data Serialization (JSON, XML, CSV): Transmit structured data across the internet as standardized text streams.

Bioinformatics and Genomics: Represent billion-letter DNA strands made of the characters `A`, `C`, `G`, and `T`.


Summary

A string is an ordered array of characters that bridges the gap between raw computer numbers and human language, text processing, and symbolic data.
