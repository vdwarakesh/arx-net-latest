FIFO Cache

A FIFO Cache (**First-In, First-Out** Cache) is a special type of cache structure that evicts items strictly in the **chronological order they were first inserted**, completely ignoring how often or how recently an item has been read since it arrived.

Imagine a rolling 30-day security camera DVR buffer or a bakery display shelf. Every new tray of bread goes in on the left pushing older trays to the right, and when the shelf is full, the oldest tray on the far right is removed—even if five customers just looked at that tray ten seconds ago. Arrival time alone decides when an item leaves.


Understanding the Basic Terminology

Arrival Order (Insertion Timestamp): The strict queue order determined solely by when a key was first added to the cache.

Zero Read-Update Overhead: Reading an existing key (`Get`) never moves pointers or updates counters, making read hits completely lock-free and ultra-fast.

Hash Map + Circular Queue Architecture: Combining a Hash Map for $\mathcal{O}(1)$ lookups with a simple FIFO Queue (or ring buffer) tracking insertion order.


How Does a FIFO Cache Work Conceptually?

In an LRU or LFU cache, every single read (`Get`) has to mutate pointers in a doubly linked list—which writes to memory and causes CPU threads to fight over locks. A FIFO cache eliminates all work during reads: when a key is read, the Hash Map simply returns the value without touching the queue at all!

Only when a brand-new key is inserted (`Put`) does it join the back of the queue, while the oldest key at the front of the queue is dequeued and deleted from the Hash Map.


Where Are FIFO Caches Used in the Real World?

High-Throughput Read-Only Network Caches: Serve millions of concurrent read requests per second without mutex lock contention on read hits.

Time-Windowed Packet & Log Deduplication: Remember the last 10,000 message IDs seen over the network to drop duplicate packets.

Modern S3-FIFO & Second-Chance Caches: Serve as the fast probationary front queue in state-of-the-art cache algorithms (like S3-FIFO and Clock).


Summary

A FIFO cache is a lightweight, arrival-ordered cache that evicts the oldest inserted item first, trading usage tracking for zero-overhead, contention-free reads.
