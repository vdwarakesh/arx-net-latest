Dynamic Array

A Dynamic Array is a type of array that can adjust its storage capacity as the number of elements changes. When its existing storage becomes insufficient, it can allocate a larger block of memory and move its elements into that space.

Imagine a bookshelf that can be extended with extra sections whenever your book collection grows. You do not need to decide the final size of the shelf before adding your first book. The collection can expand as needed, although resizing may occasionally require extra work.

Dynamic arrays are useful for shopping carts, growing lists of user records, application activity logs, and collections whose size is not known in advance. Examples include Python lists, Java ArrayLists, and C++ vectors.

A dynamic array may reserve more space than it currently uses so that future additions can fit without immediately requiring another resize. Its ability to grow is managed by the underlying implementation.


Summary

A Dynamic Array combines indexed access with flexible capacity, making it useful for collections that change in size over time.
