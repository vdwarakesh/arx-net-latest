Fenwick Tree

A Fenwick Tree (also known as a **Binary Indexed Tree**, or **BIT**) is a special type of implicit tree structure stored inside a flat 1D array that computes **prefix sums** and applies **point updates** in $\mathcal{O}(\log n)$ time using clever binary bit manipulation.

Imagine measuring a distance of 13 meters using only rulers of power-of-two lengths: an 8-meter ruler, a 4-meter ruler, and a 1-meter ruler ($8 + 4 + 1 = 13$). In a Fenwick tree, slot 13 stores 1 item, slot 12 stores 4 items, and slot 8 stores 8 items. By stripping off the lowest `1`-bit in the binary representation of 13 (`1101` $\rightarrow$ `1100` $\rightarrow$ `1000`), you add up all 13 items in just three hops.


Understanding the Basic Terminology

Least Significant Bit (`LSB` / `lowbit`): The value of the rightmost `1`-bit in an index's binary number, calculated instantly in hardware via the bitwise trick `i & -i`.

Responsibility Range: Each 1-based array slot `i` stores the sum of exactly `lowbit(i)` elements ending at position `i`.

Prefix Sum Query: Summing elements from index `1` to `i` by repeatedly subtracting `lowbit(i)` from `i` until `i` reaches `0`.

Point Update: Adding a delta to index `i` by repeatedly *adding* `lowbit(i)` to `i` up to $n$ to update all covering intervals.


How Does a Fenwick Tree Work Conceptually?

While a Segment Tree requires $4n$ memory slots and recursive tree navigation, a Fenwick tree requires an array of size **just $n$**—the exact same size as the original data! Every index `i` implicitly acts as a tree node whose parent is found by flipping or adding its lowest set bit.

Because both queries and updates consist of a tiny three-line `while` loop using `i += i & -i` or `i -= i & -i`, a Fenwick tree has virtually zero constant-factor overhead and runs several times faster than a full segment tree for cumulative sum and frequency tasks.


Where Are Fenwick Trees Used in the Real World?

Arithmetic Coding in Data Compression: Maintain live cumulative symbol frequencies in high-speed compression codecs (the exact problem Peter Fenwick invented the structure to solve in 1994).

Counting Inversions & Ranking Streams: Count how many numbers arrived out of order or maintain dynamic cumulative distribution tables.

Real-Time Financial Ledger Balances: Update transaction buckets and compute running year-to-date totals in microseconds.


Summary

A Fenwick tree packs the power of a dynamic range-sum tree into a flat array of size $n$, using binary bit jumps (`i & -i`) for ultra-compact, lightning-fast prefix sums and updates.
