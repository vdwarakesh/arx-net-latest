Fenwick Tree

A Fenwick Tree, also known as a Binary Indexed Tree (BIT), is a data structure designed to efficiently maintain cumulative information about an array. It is commonly used to calculate prefix sums, which are the sums of elements from the beginning of an array up to a specified position.

Instead of storing every possible range separately, a Fenwick Tree stores carefully chosen partial sums. Each position contributes to a particular set of these stored values, allowing the structure to combine the relevant pieces when calculating a cumulative total.

Imagine tracking daily sales in a shop. You want to know the total sales from the first day of the month up to today, but new sales arrive every day and previous figures may need correction. A Fenwick Tree helps maintain these totals without repeatedly adding every day's sales from scratch.


Where Is It Useful?

Fenwick Trees are useful for cumulative frequency tables, counting inversions in sequences, tracking running totals, and handling frequent numerical updates in competitive programming.


Summary

A Fenwick Tree is a compact way to maintain cumulative information, especially when you need frequent prefix-sum queries and individual value updates.
