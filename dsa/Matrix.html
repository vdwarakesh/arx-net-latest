Matrix

A Matrix (or **2D Array / Grid**) is a data structure that organizes elements into a rectangular two-dimensional table of horizontal **rows** and vertical **columns**, where every cell is uniquely identified by a pair of coordinates `(row, column)`.

Imagine a spreadsheet or a chessboard. Instead of lining items up in a single hallway like a 1D array, a matrix arranges data across a flat grid where you locate any square by naming its row number and column number. Every row has the exact same width, and every column has the exact same height.


Understanding the Basic Terminology

Dimensions ($M \times N$): The size of the matrix, expressed as $M$ horizontal rows by $N$ vertical columns.

Cell (Element $A[i][j]$): The value sitting at the intersection of row index `i` and column index `j`.

Row-Major vs. Column-Major Order: How a 2D grid is flattened into 1D computer memory—either laying out complete rows one after another (Row-Major, used in C/Python) or complete columns one after another (Column-Major, used in Fortran/MATLAB).

Main Diagonal: The line of cells where the row index equals the column index (`i == j`), running from top-left to bottom-right.


How Does a Matrix Work Conceptually?

Although we picture a matrix as a two-dimensional rectangle, computer RAM is actually a single one-dimensional strip of addresses. To store an $M \times N$ matrix in row-major order, the computer places Row 0 first, immediately followed by Row 1, Row 2, and so on.

When you ask for cell `(i, j)`, the computer calculates the exact 1D memory offset using the formula $\text{base} + (i \times N + j) \times \text{element\_size}$, giving you instant $\mathcal{O}(1)$ access to any cell in the grid.


Where Are Matrices Used in the Real World?

3D Graphics and Game Engines: Rotate, scale, and project 3D models onto your 2D screen using $4 \times 4$ transformation matrices on the GPU.

Artificial Intelligence & Deep Learning: Store neural network weights and process batches of data through high-speed matrix multiplications.

Digital Images and Video Frames: Represent every frame of video as a 2D grid of pixel brightness and color values.

Tabular Spreadsheets & Scientific Computing: Model systems of linear equations, weather grids, and financial tables.


Summary

A matrix organizes data into a structured 2D grid of rows and columns, serving as the mathematical and computational backbone of computer graphics, image processing, and modern AI.
