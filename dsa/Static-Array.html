Static Array

A Static Array is a type of array whose size is fixed when it is created. It can store a predetermined number of elements, and its allocated capacity does not automatically grow or shrink as the program runs.

Imagine a parking lot with exactly 50 numbered spaces. You can park cars in the available spaces, but the lot itself cannot automatically create a 51st space when it becomes full. The fixed capacity makes the storage arrangement predictable.

Static arrays are useful when the number of elements is known in advance, such as storing the days of a week, the months of a year, or a fixed set of sensor readings. Depending on the programming language, the exact rules for creating and allocating static arrays may differ.


Summary

A Static Array provides a fixed amount of indexed storage, making it suitable when the required number of elements is known beforehand.
