Suffix Tree

A Suffix Tree is a special type of tree—specifically a **compressed suffix trie**—that stores all suffixes of a string of length $n$ in just $\mathcal{O}(n)$ space and can be constructed in linear $\mathcal{O}(n)$ time by collapsing non-branching character chains into index-pair edges.

Imagine an index for an entire 500-page novel that doesn't just list major words, but indexes *every single phrase, sentence fragment, and character sequence* in the book—yet instead of copying paragraphs into the index, each branch simply lists `(Page 42, Character 10 to 85)`. That compact pointer trick shrinks a massive quadratic trie down to the size of the book itself.


Understanding the Basic Terminology

Edge Index Labels `(start, end)`: Instead of storing actual string copies on compressed edges, each edge stores two integer indices pointing directly into the original master text, keeping every edge $\mathcal{O}(1)$ in size.

Ukkonen's Algorithm: The famous online algorithm that builds a full suffix tree character by character from left to right in linear $\mathcal{O}(n)$ time.

Suffix Links: Internal shortcut pointers connecting a node for string `c + S` to the node for `S`, enabling linear-time construction and cross-string comparisons.

Generalized Suffix Tree: A single suffix tree built over multiple distinct strings (each terminated by a unique symbol `#`, `$`, `%`) to find shared substrings across documents.


How Does a Suffix Tree Work Conceptually?

An uncompressed Suffix Trie for a 1-million-character genome would require roughly 500 billion nodes and crash any server. A Suffix Tree solves this in two steps: first, it collapses every chain of one-child nodes into a single edge (guaranteeing at most $2n$ nodes total); second, it replaces the text on every edge with a pair of `[start, end]` numbers referencing the original string.

Once built in $\mathcal{O}(n)$ time, it acts as a Swiss Army knife for strings: you can find any substring of length $m$ in $\mathcal{O}(m)$ time, find the longest repeated substring via the deepest internal node, or find the longest common substring of multiple texts.


Where Are Suffix Trees Used in the Real World?

Whole-Genome Bioinformatics (MUMmer): Align massive DNA sequences and locate maximal unique matches across chromosomes in seconds.

Plagiarism & Code Clone Detection: Identify copied passages or duplicated source code blocks across large document repositories.

Data Compression (LZ77 / Deflate): Locate the longest previously seen matching byte sequence during file compression.


Summary

A suffix tree compresses all suffixes of a text into linear space and time, providing one of computer science's most powerful engines for instant full-text and genomic pattern analysis.
