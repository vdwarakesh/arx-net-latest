Bit-Based Structures

Bit-Based Structures are a family of ultra-compact data structures that store and manipulate information at the level of individual binary bits (0 and 1) rather than spending full bytes or 32/64-bit machine words on each item.

Imagine a row of 64 light switches on a control panel. Each switch can represent a True/False answer (On = 1, Off = 0). Instead of writing "True" or "False" on 64 separate sheets of paper, a single 64-bit integer in your computer's CPU already contains 64 miniature switches that can all be flipped, compared, or counted in a single clock cycle!


Understanding the Basic Terminology

Bit (0 or 1): The smallest possible unit of digital information, representing a boolean state (false/true, absent/present).

Machine Word (uint64): A native 64-bit chunk of CPU memory that packs 64 individual bits side by side.

Bit-Level Parallelism (Word-RAM): Performing bitwise operations (AND, OR, XOR, NOT, shifts) on 64 bits simultaneously in a single CPU instruction.

Hardware Intrinsics (popcount, ctz, clz): Dedicated silicon CPU instructions that count how many 1-bits are in a 64-bit word (popcount) or find the first 1-bit (ctz) in one cycle.


How Do Bit-Based Structures Work Conceptually?

In many programming languages, a standard boolean variable takes up a full 1 byte (8 bits) or more because memory addresses point to bytes, not individual bits-wasting 87.5% of the space. Bit-based structures pack 64 boolean flags tightly into each 64-bit integer of an array.

To check or flip the i-th flag, the structure divides i by 64 (i >> 6) to find the right 64-bit word, and uses the remainder (i & 63) as a bitmask shift (1ULL << (i & 63)). This shrinks memory usage by 8x to 64x while speeding up bulk set operations by up to 64x.


Where Are Bit-Based Structures Used in the Real World?

Database Columnar Indexes (Bitmap Indexes): Filter millions of rows across categories (e.g., InStock AND FreeShipping) by intersecting bit arrays at hardware speed.

Operating System Disk & Memory Allocators: Track which disk sectors or memory pages are currently free (0) or occupied (1).

Compressed Text & Succinct Data Structures: Store massive graphs, trees, and genomic indexes close to the theoretical information-theoretic minimum size.


Summary

Bit-based structures harness individual binary bits and 64-bit CPU parallelism to pack boolean flags and sets into tiny memory footprints with blistering processing speed.
