Suffix Automaton

A Suffix Automaton (SAM, also known as a Directed Acyclic Word Graph, or DAWG) is a special type of string data structure that acts as the smallest possible deterministic finite state machine capable of recognizing every suffix-and every substring-of a string in linear O(n) time and space.

Imagine compressing a massive flowchart of every possible phrase in a book by merging together any two boxes that have the exact same set of valid continuations. The resulting ultra-compact state diagram has at most 2n - 1 states and 3n - 4 arrows, yet walking from the start state along the arrows can spell out every single substring in the book.


Understanding the Basic Terminology

endpos Equivalence Class: The mathematical heart of a Suffix Automaton: two substrings belong to the exact same state node if and only if they always appear at the exact same set of ending positions (endpos) throughout the text.

Transition Edges (DAWG): Forward directed edges labeled with single characters; following any path from the initial state t0 spells out a valid substring of the text.

Suffix Links (Parent Tree): Backward links connecting each state to the state representing the longest suffix that appears in a strictly larger set of positions (endpos), forming a tree of states.


How Does a Suffix Automaton Work Conceptually?

Built online character by character from left to right (via Blumer's algorithm), a Suffix Automaton groups substrings that always travel together into single state nodes. Each state covers a contiguous range of substring lengths [minlen(v), maxlen(v)].

Because every path in the automaton corresponds to a substring and the suffix links form a clean tree, counting the total number of distinct substrings in a string is as simple as summing maxlen(v) - maxlen(link(v)) across all states in linear time.


Where Are Suffix Automata Used in the Real World?

Advanced String Analytics & Substring Counting: Compute the number of distinct substrings, shortest non-occurring string, or k-th lexicographical substring in O(n) time.

Longest Common Substring Across Multiple Texts: Stream a second text through the first text's automaton using transition edges and suffix links to find maximal matches at line speed.

Compact Dictionary and Text Indexing: Represent massive word sets and text patterns as minimal state machines.


Summary

A Suffix Automaton is a minimal state machine that folds all substrings of a text into at most 2n - 1 states, combining the power of a suffix tree with the clean transitions of a finite automaton.
