Radix Trie

A Radix Trie (also called a Radix Tree or Compact Prefix Tree) is a special type of compressed trie in which keys are broken into chunks of a fixed radix (base)-such as bytes, nibbles, or multi-character substrings-and stored along compressed edges for high-performance associative lookups.

Imagine sorting mail first by 3-digit region code, then by 2-digit post office code, and skipping intermediate sorting bins entirely whenever an entire zip code goes to a single corporate building. A radix trie adapts its branching depth dynamically to the density of the keys stored inside it.


Understanding the Basic Terminology

Radix (r): The base or chunk size used to slice keys at each branching level (for example, r=2 for single bits, r=16 for 4-bit hex nibbles, or r=256 for full bytes).

Adaptive Node Sizing: A common optimization (used in Adaptive Radix Trees) where nodes dynamically switch between small 4-slot, 16-slot, 48-slot, and 256-slot arrays depending on how many children actually branch out.

Longest Prefix Match: Finding the stored key that shares the longest matching beginning with a query key.


How Does a Radix Trie Work Conceptually?

While "compressed trie" describes the general concept of collapsing single-child chains, a radix trie applies this principle to arbitrary binary keys, integers, and strings divided into fixed-base chunks. When you search for a key, you compare the multi-byte prefix stored on an edge in a single CPU instruction, then use the next byte to index into the child array.

This gives radix tries hash-table-like lookup speeds while still keeping keys sorted in lexicographical order and supporting instant prefix scans.


Where Are Radix Tries Used in the Real World?

Web Server URL Routers: Match incoming HTTP paths like /api/v2/users/profile to their handler functions in frameworks across Go, Rust, and Node.js.

In-Memory Databases (Redis & ART): Store Redis Streams, Cluster slot keys, and high-speed database indexes.

Operating System Page Caches: Map file offsets to cached memory pages inside the Linux kernel (XArray / radix tree).


Summary

A radix trie is a practical, chunk-oriented compressed trie that powers modern web routers, operating system kernels, and in-memory databases.
