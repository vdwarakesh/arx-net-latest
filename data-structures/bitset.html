Bitset

A Bitset (also called a Bitmap or Bit Array) is a special type of bit-based structure that represents a fixed-size or bounded set of integers (or boolean flags) as a compact sequence of bits, supporting instant bit manipulation and 64-at-a-time set operations.

Imagine an attendance sheet for a class of 100 students numbered 0 through 99. Instead of writing down a list of names of everyone who showed up today, you have a strip of 100 checkboxes. If Student #42 is present, box #42 is checked (1); if absent, it is blank (0). Comparing Monday's attendance with Tuesday's attendance is as easy as laying the two strips on top of each other.


Understanding the Basic Terminology

Set(i) / Reset(i) / Flip(i): Setting bit i to 1 (|= (1 << i)), clearing bit i to 0 (&=~(1 << i)), or toggling bit i (^=(1 << i)).

Test(i): Checking whether bit i is currently 1 or 0 in constant O(1) time.

Bitwise Set Intersection & Union: Computing the intersection of two sets via bitwise AND (A & B) or their union via bitwise OR (A | B), processing 64 elements per CPU instruction.

Count() (popcount): Counting the total number of 1-bits in the bitset using fast hardware population-count instructions.


How Does a Bitset Work Conceptually?

A bitset of size N allocates an array of ⌈N / 64 ⌉ unsigned 64-bit integers. Every integer x ∈ [0, N-1] corresponds directly to the x-th bit in that array.

Because the CPU applies bitwise AND, OR, XOR, and bit-shifts to whole 64-bit words at once, operations that normally take O(N) steps on a standard array take O(N / 64) steps on a bitset-turning slow loops into cache-friendly, single-instruction sweeps.


Where Are Bitsets Used in the Real World?

Sieve of Eratosthenes (Prime Number Generation): Mark composite numbers up to billions using minimal RAM that fits cleanly inside CPU cache.

Permission Flags & Feature Toggles: Pack dozens of user permissions or hardware status registers into a single integer word.

Graph Transitive Closure & Subgraph Matching: Speed up triangle counting, clique finding, and reachability queries by a factor of 64 (std::bitset in C++).


Summary

A bitset maps integers and flags directly to individual bits inside 64-bit machine words, delivering an 8x-64x memory reduction and 64x faster bulk set operations.
