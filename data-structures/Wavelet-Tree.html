Wavelet Tree

A Wavelet Tree is a special type of binary tree that recursively partitions a sequence of values by their alphabet range (rather than by array position) while preserving their original left-to-right order using compact bitvectors at every node.

Imagine sorting a deck of cards numbered 1 through 8 without losing track of how the deck was originally shuffled. At the top node, you don't move the cards; you simply write down a 0 for every card ≤ 4 and a 1 for every card > 4, then deal the 0 cards to the left child and the 1 cards to the right child in their exact original order, repeating until each leaf holds a single card value.


Understanding the Basic Terminology

Alphabet Partitioning: Unlike a Segment Tree (which splits array positions [L, R] in half), a Wavelet Tree splits the value range [σlow, σhigh] in half at each level.

Node Bitvector: A compact array of 0s and 1s at each node recording whether each element fell into the lower half (0) or upper half (1) of the current value range.

Constant-Time Rank Queries on Bitvectors: Counting how many 0s or 1s appear up to index i in O(1) time, which lets you map any subarray [L, R] down to a child node in a single step.


How Does a Wavelet Tree Work Conceptually?

Because each node's bitvector supports O(1) rank queries (counting 0s and 1s up to any position), you can translate any subarray range [L, R] at the root into the corresponding range of elements in the left or right child instantaneously-without storing full subarrays or doing binary searches.

Walking down the O(log Σ) levels of the alphabet lets you answer three kinds of queries on any arbitrary subarray [L, R] in O(log Σ) time: finding the value at index i (Access), counting occurrences of character c (Rank), and finding the k-th smallest value (Quantile).


Where Are Wavelet Trees Used in the Real World?

Compressed Full-Text Indexes (FM-Index): Store and search massive compressed text corpora and Burrows-Wheeler Transforms without decompressing them first.

Information Retrieval & Search Engines: Intersect inverted document lists and perform ranked range searches over document IDs.

2D Spatial & Range Quantile Queries: Find medians and percentiles over arbitrary slices of large datasets using minimal memory.


Summary

A wavelet tree splits data by value ranges using compact bitvectors, enabling fast range quantile, frequency, and compressed-text queries in minimal space.
